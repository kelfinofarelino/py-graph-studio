# Pro Graphics Studio 🎨

A comprehensive interactive graphics suite built with **Python** and **PyQt6**. This project demonstrates the manual implementation of fundamental computer graphics algorithms without relying on built-in drawing functions for primitives.

## ✨ Features
* **Manual Rasterization:** * Line drawing using **Bresenham Algorithm**.
    * Circle & Ellipse drawing using **Midpoint Algorithm**.
    * Area filling using **Flood Fill**.
* **Interactive Transformations:** * Translation (Move), Rotation, Scaling, and Shearing.
    * Arbitrary line reflection (Mirroring).
* **Object Management:** Selection system based on bounding boxes.
* **Modern UI:** Clean sidebar for color palettes and a categorized toolbar.

## 🚀 Version History
* **v1.0.0**: Basic shapes (Line, Rect, Triangle) and transformations.
* **v2.0.1**: UI overhaul with categorized toolbars and improved selection.
* **v3.0.0 (Current)**: Added manual Circle and Ellipse primitives using midpoint algorithms.

## 🛠️ Installation & Usage
1. Clone the repository:
   ```bash
   git clone [https://github.com/kelfinofarelino/py-graph-studio](https://github.com/kelfinofarelino/py-graph-studio)
   ```
2. Install dependencies:
   ```bash
   pip install PyQt6
   ```
3. Run the application:
   ```bash
   python v2.1.1.py
   ```
